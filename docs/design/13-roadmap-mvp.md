# 13 — MVP vs Full Version Roadmap

## Phase 0 — Pre-production (6–8 weeks)
- Lock this design doc set; build the balancing spreadsheets (doc 15 §4).
- Art style-lock sprint (doc 11 §6 step 1): 7 hero canons + 4 enemy canons + 4 key arts. **Gate: contact sheet reads as one premium game.**
- Battle sim as pure C# library: combat model, status taxonomy, 10 test kits, headless sim runner + auto-balance reports (all-Common-clears-3-10 guardrail etc.).
- Backend skeleton: auth, inventory, config pipeline, one deployable environment.

## Phase 1 — Vertical Slice / MVP (12–16 weeks)
**Definition: "one perfect chapter" — proves fun, look, and loop.**
- Combat presentation: full battle scene, 1 VFX kit per class, ult cut-ins for 2 units.
- Content: Chapter 1 complete (10 stages + Krul), 21 characters (3 per class: 1 C, 1 R, 1 E), levels + gear (2 sets) + star-ups, Starfall + Foundry raids T1.
- Systems: home hub v1, standard banner + pity, daily quests, Aether, Gold, Crystals.
- FTUE through stage 1-10.
- **Gate: internal playtest D1 retention proxy + "would you pull?" test; battle readability test on 6-inch device.**

## Phase 2 — Content Build-out (14–18 weeks)
- Full 70-unit roster (class batches, doc 11 §6), chapters 2–4, all bosses, Hard mode.
- Ascension, skill manuals, Reliquary raid, full gear sets (6), dupes/Soul Shards, Mercy Forge.
- Featured banner + Vowkeeping carryover, Beginner's Vow, trial stages.
- Guild v1 (roles, chat, Expedition Board), **Co-op Expedition** (2p first, then 4p), reconnect/AI-takeover.
- **Gate: full-economy sim run — 90-day simulated F2P/dolphin/whale progression matches doc 10 §2 targets.**

## Phase 3 — Launch Readiness (8–10 weeks)
- Battle pass, Monthly Vow Card, shop, first two events built and scheduled.
- Live-ops tooling, analytics dashboards, CS tools (player lookup, grants, rollback).
- Localization pass (EN master + framework proof in 1 extra language), store assets from marketing pipeline (doc 11 §5).
- Soft launch (2–3 mid-size markets): tune FTUE funnel, D7, stall heatmap, pricing. Exit criteria: D1 ≥ 40%, D7 ≥ 15%, FTUE completion ≥ 70%, crash-free ≥ 99.5%.
- Global launch with 8 weeks of content calendar already banked.

## Post-launch Year 1 (thematic quarters)
- Q1: cadence proof — banner every 2 weeks, event alternation, first new-unit releases (1–2/month, pre-built from roster expansion slots), QoL from telemetry.
- Q2: Chapter 5 (new enemy family), 4p Expedition variants (new boss), skins program start.
- Q3: second progression sink for veterans (gear substat refinement OR "Transcendent" showcase content), collab-scale event tech.
- Q4: evaluate elemental/PvP-lite/roguelite side mode from data — **not before**.

## Explicitly cut from launch (recorded so nobody "helpfully" adds them)
PvP, elemental wheel, guild wars, real-time netcode combat, housing, pet systems, auto-battler side modes, randomized IAP boxes.
